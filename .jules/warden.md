**2025-03-23 - Prevent memory exhaustion DoS in username/password flow**
**Threat:** A malicious or misconfigured server could return an infinitely large response body to the `/services/oauth2/token` endpoint during authentication failure. This would cause `UsernamePassword::send_token_request` to load the entire body into memory, leading to an Out of Memory (OOM) panic and a potential Denial of Service (DoS) attack.
**Defense:** Replaced unbounded stream-reading logic with the safe, centralized `crate::http::error::read_capped_body` which limits the read size to 1MB and stops allocating memory once the limit is reached.
