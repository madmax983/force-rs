**Pre-allocate QueryInsights vector capacity**
**Learning:** Initializing the `QueryInsights` struct using `..Default::default()` created the `insights` vector with zero capacity. Since `QueryInsights` represents the parsed result of `ExplainResponse`, whose length `response.plans.len()` is directly available before initialization, relying on default caused unnecessary dynamic heap reallocations when pushing elements to `insights.insights`.
**Action:** Always explicitly initialize dynamic collections within structs using `Vec::with_capacity(known_size)` when the input boundaries are known at instantiation time, rather than relying on `..Default::default()`.
