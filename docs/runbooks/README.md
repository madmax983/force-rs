# Runbooks

Operational runbooks for `force-rs` production usage.

- `auth-credential-rotation.md`: rotate Salesforce auth credentials with minimal downtime.
- `rate-limit-incident.md`: triage and mitigate `429` / `REQUEST_LIMIT_EXCEEDED` incidents.
- `retry-tuning.md`: tune retry and polling behavior safely.
- `salesforce-api-version-upgrade.md`: upgrade and validate Salesforce API versions.
